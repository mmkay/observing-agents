Note:
Claude Code is great at showing you the cost-related metrics. If you want to create a dashboard that shows how much you're milking the subsidized plan, you can easily find out you're using your monthly plan price in tokens in a day. You can also see a pricing drift or the token throughput.

You can't really use these metrics for alerting though - which is understandable given how we interact with agents as tools that enhance us (or sometimes make us dumber).
