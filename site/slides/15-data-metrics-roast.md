# And a light roast

![OpenClaw generated usage report](images/openclaw-usage-report.png)

Note:
Based on the metrics I gathered, I created a recurring job to go through the metrics from the last day and provide me with a summary of my LLM usage. This is an example report from one of the days. You can spot that even though I used OpenCode, it didn't see any cost - that's because I was using Github Copilot as its provider.

For a bit of whimsy, I also asked the agent to roast my LLM usage a bit. It was fun for the first three days, then it became way too repetitive.
