# OpenClaw convinced me to send this talk

![A message from OpenClaw on Telegram sent on Feb 28, telling that the CFP for Devoxx Poland closes on this day and prompting to submit a talk](images/openclaw-prompt.png)

Note:
I have been experimenting with software agents for some time, when I noticed a hype wave around OpenClaw. It is different from what I expected - imagine a very fragile agentic flow in a loop that burns millions of tokens every day - but in the right context it can be useful - especially if you're on a flat rate plan for tokens. One of the ideas that worked well for me for some time, until OpenClaw forgot it should do it, was a weekly task that looked for conferences I should send a submission for. And on February 28th, right on the final submission day, it showed me Devoxx. I had an idea ready in an hour - and here we are.
