Note:
Which coding tool has the best metrics? It depends on what do you want to get from these metrics. Claude is great at showing you the cost-related metrics. If you want to create a dashboard that will show you how much you're milking the subsidized plan, you can easily find out you're using your monthly plan price in tokens in a day. You could also see a pricing drift or the token throughput.

However, if you want to see which tools your agent has been using and some stats on how long did it take to use these tools, it's Github Copilot's metrics that can provide that. In all cases, however, you can't really use these metrics as something you could set up alerts on - which is understandable given the way we interact with agents - as a tool that enhances us - or sometimes makes us dumber.
